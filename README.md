# OOP Lab Exercises

A collection of Java lab exercises demonstrating core **Object-Oriented Programming (OOP)** concepts including inheritance, polymorphism, encapsulation, and more.

---

## Exercises Overview

| Exercise | Topic | Description |
|---|---|---|
| labexercise3 | Conditionals & Loops | `AsciiValue` — maps a character input to its ASCII value using if-else chains; `ValueDeterminator` — finds the highest and lowest among 5 user-entered numbers |
| labexercise4 | Arrays & Number Systems | `DecimalConverter` — converts a decimal number to binary, octal, or hexadecimal; `NumberToWords` — takes an array of numbers and prints each as its English word equivalent |
| labexercise5 | Methods | `Operations` — demonstrates static methods for sum, product, difference, and quotient with a menu-driven loop |
| labexercise6 | Classes & Objects | `AddressBook` — a CRUD app using `AddressBookEntry` and `AddressBookMethod` classes to add, delete, view, and update contact entries |
| labexercise7 | Encapsulation | `Encapsulation` — a `Triangle` class with private fields and getters/setters to calculate triangle area |
| labexercise8 | Inheritance | `Inheritance` — a `Fruit` base class with `Apple`, `Orange`, and `Mango` subclasses each inheriting and extending its behavior |
| labexercise9 | Polymorphism | `Polymorphism` — method overriding on a `Calculate` base class to compute areas of `Circle`, `Square`, and `Triangle` |

---

## Concepts Covered

- **Conditionals & Loops** — if-else chains, do-while loops, and switch statements
- **Arrays** — declaring, populating, and iterating over arrays
- **Methods** — static methods, parameters, and return values
- **Classes & Objects** — designing classes, constructors, and object interactions
- **Encapsulation** — private fields with getters and setters
- **Inheritance** — subclasses extending a base class and reusing its methods
- **Polymorphism** — method overriding with `@Override` for different behavior per subclass

## Running an Exercise

**1. Clone the repository**
```bash
git clone https://github.com/sagosaruiz1/oop-lab-exercises.git
cd oop-lab-exercises
```

**2. Navigate to an exercise**
```bash
cd src/labexercise9
```

**3. Compile and run**
```bash
javac Polymorphism.java
java labexercise9.Polymorphism
```

> Replace `Polymorphism.java` and `labexercise9.Polymorphism` with the relevant file and class name for other exercises.
